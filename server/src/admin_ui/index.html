Type the one-time token this server printed in its log when it started. On Unraid or Synology, open the container's Logs.

Each token works once. Restart the server to get a new one.

Your server is off. Start it and you get an invite to send to your friends. Nothing to configure: no domain, no port forwarding, no account.

On Windows, the first start may show a Windows Firewall prompt for “skwod”. Choose Allow (Private networks is enough). It lets friends connect to you directly; if you decline, they can still connect through a relay, only slower.
